# Ball Balance · Windows 플레이 테스트

이 저장소는 플레이어용 실행 파일을 배포합니다.

## 다운로드

[**Windows 자동 업데이트 실행기 받기**](https://github.com/minhy0905/ballslop-releases/releases/latest/download/BallBalanceLauncher.exe)

[업데이트 내역과 수동 설치 파일](https://github.com/minhy0905/ballslop-releases/releases)

1. `BallBalanceLauncher.exe`를 한 번 내려받습니다.
2. 실행하면 최신 게임을 다운로드하고 실행합니다.
3. 이후에도 같은 실행기를 사용하세요. 새 버전이 있을 때 자동으로 설치합니다.

Windows 10/11 및 .NET Framework 4.8 대상입니다. 게임 파일은 사용자 LocalAppData 폴더에 설치됩니다. 다운로드가 실패하면 기존 게임을 보존하며 재시도할 수 있습니다. 온라인 친구방 참가자는 같은 배포 버전을 사용해 주세요.

수동 설치 시에는 릴리스의 `BallBalance-Client-Windows.zip` 전체를 압축 해제하세요. EXE만 따로 꺼내면 실행되지 않습니다.

실행기는 아직 코드 서명되지 않아 Windows에서 게시자 확인 경고가 표시될 수 있습니다.

게임 소스, 전용 서버, 개발용 디버그 파일은 공개 배포에 포함하지 않습니다.
